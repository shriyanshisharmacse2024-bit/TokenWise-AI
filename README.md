## About Project
TokenWise AI is an intelligent coding agent designed to reduce unnecessary prompt context and make AI token usage more efficient.

## Features
- AI-based code generation
- Java and Python support
- Prompt optimization
- Token usage estimation
- Code output dashboard

## Technologies
- HTML
- CSS
- JavaScript
- Python
- Flask

## How to Run

1. Install Python.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   python app.py

4. Open http://127.0.0.1:5000
